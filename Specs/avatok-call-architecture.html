📞 AvaTOK Calling — the new architecture

Everything rebuilt on two clean lanes: Stream carries anything with an AvaTOK app on the line; Ava (Gemini) answers phone-line calls with no Stream in the path — until a live transfer bridges the two.

Stream network Ava container (Gemini Live) Phone carrier (DID) Your Worker (rules · billing · inbox)

🛣️ The two lanes

Lane 1 — Stream in-app a/v

Any call with an AvaTOK app on at least one end
  • 1:1 audio & video calls default
  • Group calls (≤25) default
  • AvaLive livestreams livestream
  • 1:1 consult rooms default

Lane 2 — Ava reception no stream

Phone-line callers & missed calls — invite-only, never in normal calls
  • DID number → Ava answers carrier → Gemini
  • Missed in-app call → Ava record → inbox
  • Message taken → inbox same as today
  • Live transfer to owner bridges to Lane 1

🔀 Flow 4 — live transfer: "let me connect you" now in scope

✅ Owner answers

Caller and owner talk live. Stream bills only the bridged minutes of this one call. Ava can whisper a one-line summary to the owner before leaving.

🔕 Owner declines / no answer

Ava seamlessly resumes: "He's not available — can I take a message?" → message flows to the inbox as usual. The caller never hears dead air.

This is the only place the two lanes meet — and the only DID scenario that touches Stream. It ships with the receptionist phase (P3).
