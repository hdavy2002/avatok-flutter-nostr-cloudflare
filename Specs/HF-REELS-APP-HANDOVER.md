## 0. In one paragraph

Hello Fraands lets fans watch short videos (reels) from Indian social-media influencers and then **talk to that influencer on a private, masked phone call**, paid per minute from a rupee wallet. Calls can happen right now (if the influencer is online), or the fan can book a time slot.

We have built a **screens-only demo app**: every screen exists, every button goes to the right screen, and all data is dummy and in memory. The owner installed it from Play internal testing to check the look and the flow. **Your job is to wire every screen to the real backend so it becomes a full working app.** You also need to build the influencer **Channels** onboarding, which is not in the demo yet (§6). Ship each step to the **same Play app and the same tester link**, so the owner's phone just updates.

## 2. Rules for how you work (owner's standing rules — do not skip)

1. **No local builds.** The Mac has no Flutter or Android SDK, and you must never install one. Builds run only on GitHub Actions: `.github/workflows/hf-flutter.yml`.
   - `mode=check`: analyze, tests and brand check (any branch).
   - `mode=apk` / `mode=aab`: signed artifact (main only).
   - `mode=internal`: AAB uploaded to the Play **internal** track (main only). **Run it only when the owner asks.**
   - Command: `gh workflow run hf-flutter.yml --ref main -f mode=internal`.
   - versionCode = 2000 + GitHub run number, so it always goes up by itself.
   - A cloud sandbox with Flutter 3.41.x is fine for `flutter analyze`, `flutter test` and web screenshots.
2. **The same app and link forever.** Keep package `com.hellofraands.app` and the same upload key (secret `HF_UPLOAD_KEYSTORE_BASE64`). Never create a new Play app. The owner reuses the tester link above.
3. **One issue per worktree.** For each issue:
   - `git worktree add ../wt-<id> -b issue/<id> origin/main`;
   - commit with `python3 scripts/git_safe_commit.py "[ID] msg" <paths…>`;
   - `git rebase origin/main && ALLOW_PUSH=1 git push origin HEAD:main`;
   - remove the worktree, delete the branch, run `scripts/git_hygiene.py`.
4. **Brand name and domain** live only in `Specs/brand.json`. In Dart use `Brand.name` / `Brand.supportEmail` from `lib/core/brand.dart`, which is generated by `scripts/gen_brand.py`. Never hand-edit that file, and never type the brand as a literal; a CI guard checks this.
5. **Feature flags.** New backend behaviour goes behind a flag that is declared in `worker/src/routes/config.ts` (PlatformConfig and DEFAULTS) in the same change. Prove the flag can be flipped after deploy.
6. **Rulebook.** Add or adjust rules in `Specs/RULEBOOK-HELLO-FRAANDS.md` with a change-log line in the same commit.
7. **Plain English** in all app text. Nothing under 14 sp. No green. Comfortaa and Nunito fonts.
8. **Telemetry.** Add new events to `Specs/SPEC-2026-09-02-TELEMETRY-CATALOG.md` first. Report every fetch failure.
9. **Payment gateway name is never shown in the app** (it is Cashfree; see §5.4).
10. Calls are **normal phone calls** placed by Vobiz. There is no in-app VoIP, no messaging between people, and no CALL_PHONE, contacts, SMS or location permissions.

## 3. The product, as decided by the owner

### 3.1 Fans
- **Watch first, sign up to act.** Anyone can watch reels and open profiles. Sign-up is asked only on Call now, Book, Favourite or Invite. (HF-REEL-11)
- **Fan sign-up:** name, email, WhatsApp number. (Open question: verify WhatsApp by OTP, or just collect it?)
- **Bottom bar:** Reels · Search · Favourites · Me.
- **Reels feed:** vertical swipe. It shows **only online influencers**. Every reel has Call now, a profile icon and a favourite heart.
- **Search** shows three groups: Online, Offline, and Not on Hello Fraands. For the last group, tapping **Invite** counts as **one vote**, and we ask the most-wanted names to join. (HF-REEL-9)
- **Booking:** pick a date (open dates are highlighted), then a time, then confirm. Confirming holds 10 minutes of the rate from the wallet. At the booked minute we ring the influencer first, then the fan. (HF-REEL-19)
- **Wallet:**
  - Top up any amount (minimum ₹10) through the gateway.
  - The price includes 18% GST, so **wallet credit = amount paid ÷ 1.18**, floored to the paisa. For example, ₹500 paid gives ₹423.72.
  - Ask for confirmation at ₹1,000 or more.

### 3.2 Influencers
- **Joining:** basic details, then **Channels** (§6). The automatic check is **at least 10 subscribers/followers** on YouTube or Instagram, done by the **treg** API. If the check passes, the person is accepted automatically.
- **Bottom bar (influencer side):** Home · Bookings · **Online/Offline** (round button in the centre) · Availability · Fan view. (HF-REEL-15)
- **Online** = shown as online on the web and in the app, reels appear in the feed, and fans can Call now.
- **Offline** = do not disturb: no instant calls, reels leave the feed, **but fans can still book her open slots**, and booked calls still ring. (HF-REEL-16)
- **Bookings calendar:** who booked, on which date and at what time. (HF-REEL-17)
- **Availability calendar:** open or close dates, pick time slots, set the per-minute rate. Fans can book only open slots. (HF-REEL-18)
- **Reels source:** her own channels. Only videos with **her face in the first seconds** go on the feed; the face check runs in **jev**. She can remove any video.
- **Payout:**
  - ₹500 minimum;
  - a 7-day hold on earnings;
  - every request checked by hand;
  - the UTR (bank transfer reference) is sent on WhatsApp.
- **Demo influencers** seed the feed at launch. Each one is flagged `is_demo` so one switch hides or deletes them all. (HF-REEL-12)

### 3.3 Calls (existing rules HF-CALL-1…6 still apply)
1. The influencer's phone rings first with a private announcement. She presses 1 to accept or 2 to decline.
2. Then the fan is dialled.
3. Both hear a short safety notice, then the calls are joined. Neither person sees the other's number.
4. `#` at any time ends the call, blocks the other person and reports the incident.
5. Billing is per started minute from the wallet, with a 2-minute reserve at the start.
6. If the influencer is busy or offline, the fan gets **Notify me** (one WhatsApp when she comes online). There is no queue.

### 6.2 Screens
1. **Channels list** (`/inf/channels`)
   - One card per connected channel: platform icon, @handle, follower count, status chip, last sync time.
   - Status chips: Checking… · Approved · Needs 10+ followers · Disconnected.
   - Buttons per card: **Resync** and **Remove**.
   - Big button: **+ Add a channel**.
   - Empty state: "Add your Instagram or YouTube so fans can see your reels."
2. **Pick a platform** (`/inf/channels/add`)
   - Tiles: **Instagram**, **YouTube**, **Facebook** (Facebook can say "coming soon" if treg doesn't support it).
3. **Channel consent** (`/inf/channels/add/:platform`), one screen per platform:
   - Field: your @handle or channel URL (validated per platform).
   - Consent checkboxes (all required; store consent_version and time):
     - "Show my public videos from this channel as embeds in the Reels feed and on my profile."
     - "Show my follower, like, comment and video counts."
     - "Only videos with my face in the first seconds go on the feed. I can remove any video."
     - "This channel is mine." (owner proof below)
   - **Ownership proof** (needed, or anyone could add a famous creator's channel). Pick one per platform, depending on what treg supports:
     - (a) a one-time code that she puts in her bio or channel description, then we check through treg; or
     - (b) official OAuth: Instagram Login (Business/Creator) or Google OAuth `youtube.readonly`.
     - Recommendation: (a) for launch, because it is simple and works for any account size.
   - Button: **CONNECT**.
4. **Checking** (`/inf/channels/:id/checking`)
   - Shows "Checking your channel… This takes a minute."
   - The server calls treg: confirms the handle exists, reads follower/subscriber count, verifies the bio code, and pulls recent reels.
5. **Result**
   - **Approved:** "You're in! N reels imported, M passed the face check." Button: **GO TO MY DASHBOARD**.
   - **Not yet:** "We need at least **10** followers or subscribers on YouTube or Instagram." Buttons: **Try another channel** and **Check again later**.

### 6.3 Acceptance rule (owner, 2026-10-19)
- Accept an influencer when **at least one** connected YouTube or Instagram channel has **≥ 10 subscribers/followers**, checked automatically through the **treg** API.
- Keep the threshold in config (`hfInfluencerMinFollowers`, default 10) so the owner can change it without a release.
- Re-check followers on every sync (daily cron). If all channels drop below the threshold or are disconnected, the influencer is hidden from the feed (not deleted) and gets a WhatsApp alert.

### 6.4 Reels import
- On approval and then daily: pull the latest N videos per channel from treg (URL, embed URL, thumbnail, caption, likes, comments, views, published time).
- Send each video to **jev** for the face check (face in the first seconds). Pass → `visible=true`.
- The influencer can hide any video. Disconnecting a channel hides all its reels.

## 9. Suggested build order (one issue each, ship to internal testing after each phase when the owner asks)
