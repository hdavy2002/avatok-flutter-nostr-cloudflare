# hf-flutter

The native Android app (Flutter). Same package and upload key as the Capacitor app in `hf-app/`, so it installs as an update.
There is no Flutter or Android SDK on the Mac: everything compiles in CI (`.github/workflows/hf-flutter.yml`, run with
`gh workflow run hf-flutter.yml --ref main -f mode=check|apk|aab`).

## Layout

```
lib/main.dart, app.dart          entry, root widget, link listener
lib/core/
  brand.dart                     GENERATED by scripts/gen_brand.py (never edit, never type the brand elsewhere)
  env.dart, strings.dart         origins, telemetry constants; shared copy
  api/                           ApiClient (+ HttpApiClient), ApiError
  auth/                          ClerkClient (ticket sign-in), HfMe, session.dart (providers + SessionController)
  storage/                       secure store, account scoping (scopedKey), JsonCache
  analytics/, config/            PostHog wrapper; /api/config flags
  router/                        routes.dart, deep_links.dart (path table), app_router.dart, tab_shell.dart, nav.dart
  theme/, format/, widgets/      tokens + theme, Money, shared widgets (import widgets/widgets.dart)
lib/features/<x>/ui/             one folder per feature; every route already has a stub screen here
test/                            core/ (pure), features/ (widget), support/ (FakeApiClient, FakeClerk, app_harness)
```

## Add a screen

1. Replace the stub widget in `lib/features/<x>/ui/` (the route, its parameters and sign-in rule already exist in `app_router.dart` and `routes.dart`).
2. Build it from `core/widgets/widgets.dart`. Use `AsyncValueView` for loading / content / empty / error.
3. Call the API with `ref.watch(apiClientProvider)`: `getJson`, `postJson`, ... Errors are `ApiError`; show `error.userMessage`.
4. Gate an action with `if (!await requireSignIn(context, ref)) return;`.
5. Add the screen's events to the telemetry catalog and a ship-manifest entry.

## Test a screen

```dart
final api = FakeApiClient()..onJson('GET', '/api/hf/hosts', {'hosts': []});
final c = await pumpApp(tester, session: signedInState(), api: api, location: '/explore');
expect(api.callsTo('GET', '/api/hf/hosts'), hasLength(1));
```

## Rules

Nunito headlines, Comfortaa text, light and colourful, rounded, never green, nothing under 14 sp, full width.
Money and tokens are displayed with `Money` and never computed on the phone. Per-user local state goes through `scopedKey`.
